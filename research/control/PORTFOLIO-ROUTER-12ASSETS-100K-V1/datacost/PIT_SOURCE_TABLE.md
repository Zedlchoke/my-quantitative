# PIT_SOURCE_TABLE — PORTFOLIO-ROUTER-12ASSETS-100K-V1 (Lane L1, 2026-09-28)

Purpose: for every macro/event source the strategy corpus (FOREX-UNIFIED-
STRATEGY-BRAINSTORM-V1, 1,200 HYPOTHESIS/NOT_RUN ideas) references, define the
point-in-time join rule a backtest MUST use, the vintage risk, and the repo
evidence status. Definitions used throughout:

- **event_time** — when the measured phenomenon happened (e.g. CoT positions
  as of Tuesday open).
- **publication_time** — when the world could first read it.
- **effective_time** — when the number takes legal/economic effect (rates).
- **available_at (join key)** — the earliest timestamp at which the INVESTOR
  in a backtest may legitimately use the value = publication_time (never
  event_time, never effective_time-as-publication).

Standing law: a current-vintage series downloaded today is NOT PIT history
(see OFR current-vintage caveat, row 7). Missing evidence = UNEVIDENCED, never
inferred.
