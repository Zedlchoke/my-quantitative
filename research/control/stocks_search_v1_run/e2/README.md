# E2 lane — STOCKS-SEARCH-V1 streaming scored-engine remediation (ssearch-e2)

Owner remediation decision (a) recorded in the registry phase of
STOCKS-SEARCH-V1 (TECHABORT_PRESERVED, 2026-09-19): streaming/out-of-core
E-engine + fresh GO. This lane implements it. The frozen chain
(`i/`, `e/`, `s/`, `d1/`, `p0/`, `m0/`, `z/`, `audits/`) is READ-ONLY
evidence; this lane reuses its code unmodified via import.

## What changed and what did not

NOT changed (frozen experiment): universe, folds, clock, cost bands,
configurations, controls, selection, the 3 scored cells, thresholds,
gates, data, cost model. No S1. No rescue.

Changed (engine ONLY, scientifically equivalent by construction +
measured equivalence):

| frozen path defect (e/e_run_verdict.json) | e2 remediation |
|---|---|
| `load_real_data` materializes every NameData (~8.5 GB) | `stream_iter_names` parses one name at a time |
| `build_all_books` materializes every Leg (~10.7–30.5 GB/cell) | legs stream into on-disk spill files; P-11 book_log accumulates in exact leg order |
| adjudication deepcopy doubles the books | adjudication mirror consumes streaming aggregates; BC-7 included variant precomputed |
| no crash-resume | generation-numbered atomic checkpoints; spill truncation to committed record counts; census-based skip (no re-parse) |
| no disk guard | per-cell spill quota 6 GiB fail-closed; refuse start under 6 GiB free; abort under 2 GiB free |
| RSS interlock after the fact | fresh-subprocess RSS probe of the streaming engine BEFORE the scored launch (hard bound 1.5 GiB) + live watchdog 5.5 GiB |

## Equivalence law (preregistered)

Primary gate: BIT/BYTE equality — every float array bitwise, every
verdict canonical-JSON equal — between the reference engine
(`i_engine.build_all_books` + `adjudicate.adjudicate_candidate`) and the
streaming engine (`i_stream_engine` + mirror), on (a) a synthetic
edge-case cohort over the real SPY calendar/folds and (b) a bounded
deterministic real-subset cohort (digest-only persistence, never scored
evidence). A mismatch anywhere is FAIL - never auto-passed. The comparison is STRICTLY bitwise/byte-equal - there is no wired
tolerance fallback at all (A7 finding E2F-6: the README previously
described an unwired 1e-12 fallback; the code is stricter than that
description). Determinism: two independent streaming runs must be
bit-identical.

Why bitwise equality holds by construction: `i_engine.build_legs` is
reused UNMODIFIED per name; masks reuse the frozen functions; np.mean
over the spilled float64 sequence reproduces the reference pairwise
summation over the same values in the same order; statistics.stdev over
per-fold masked arrays reproduces the reference per-fold lists; book_log
additions happen in identical leg order (names sorted, decisions
sorted); the SPY benchmark reference is pinned before any name streams.

## Prelaunch gate (all required before the owner GO)

1. `selfcheck.py` PASS (10/10).
2. `equivalence.py --synthetic` PASS (3 cells × bitwise).
3. `equivalence.py --real-subset` PASS (digest-only).
4. `--probe-stream-rss` peak RSS ≤ 1.5 GiB in a fresh subprocess.
5. Fresh-context A7 audit: scientific equivalence of the mirror +
   streaming semantics, resource evidence, frozen-experiment integrity,
   honest-labeling. Zero unresolved HIGH/CRITICAL.
6. Owner types exactly: `GO STOCKS SEARCH V1 SCORED EXECUTION`
   (the old GO was never consumed by a scored path; it stays dead — a
   fresh phrase typed in the GO turn is required).

The scored run is then launched with `SSEARCH_E2_GO_PHRASE` set from the
owner's exact phrase. Budget 0/3 → at most 3 cells. R0 NOT_RUN (D2
skipped, §3b) and PBO NOT_RUN labels carry verbatim on every result.
